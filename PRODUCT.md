# PIMX MOJI

PIMX MOJI turns a person's images into ASCII portraits, word mosaics and color-matched emoji art in the browser. The audience is people making personal artwork, avatars and social posts. The main action is to open an image, choose and preview a style, then explicitly Generate. The finished artwork opens on its own page with download controls.

Preserve Persian/English, RTL, light/dark themes, image uploads, camera and video, brushes, undo/redo, comparisons, local project storage, custom styles, batch export, PNG/GIF/video/text export. Private source images stay local. Do not invent usage figures or testimonials.

The user requests a full redesign, 300 real presets, all editor settings on one continuous page, responsiveness starting at 300 CSS pixels and substantially less lag. They explicitly selected black, silver and electric blue/violet, rejected the green interface, and requested 3D depth, animation, transitions and natural human copy. Motion must respect reduced-motion and avoid making the editor slow. Existing uncommitted work belongs to the user and must be preserved.

The latest brief removes Community and every server dependency. All images/projects and custom styles live in IndexedDB, with a full portable backup/merge restore. The studio shows all 300 style names with temporary hover/focus preview on the user image. All sample style previews use portrait.jpg (the woman). The global navbar stays visible while scrolling. Enrich home and secondary pages with real demonstrations and clear backup instructions.

The current studio brief removes the separate persistent live-preview box. Temporary previews belong above the style list, with a separate Preview button beside names on touch/Android. Final output requires Generate and a dedicated result page. Simplify the studio through progressive disclosure on one page, preserve all tools, expand motion beyond six effects (18 implemented), and redesign the footer.
