## ⚡ Features
- 🎭 **152 Creative Styles**: Instant rendering across ASCII, Emoji mosaics, Halftone, Cyberpunk, and Oil Painting filters.
- ⚡ **100% Client-Side**: All Canvas manipulation runs locally in the browser with zero image upload latency.
- 📱 **Full Bilingual Experience**: Native English and Persian (RTL) interfaces with preset export options (PNG/SVG/Text).
